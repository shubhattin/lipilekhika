Lipi Lekhika supports all the **Modern Indian Scripts** including Devanagari, Bengali, Kannada, Gujarati, Telugu, Tamil, Malayalam, Odia, Assamese, Gurumukhi and Sinhala. It also supports several **Classical and Historical Scripts** like Brahmi, Granth, Modi, Sharada, and Siddham. There are also two special output targets _Normal_ and _Romanized_, and the **Standard Romanization Schemes** IAST, ITRANS, Harvard-Kyoto and SLP1.

What each script is, and how Normal and Romanized differ from the standard schemes, is in the [Script Guide](/reference/script_guide).

## Supported Scripts

### Modern Scripts
- Devanagari (dev)
- Telugu (te, tel)
- Tamil (tam)
- Tamil-Extended (tam-ex)
- Bengali (ben, be)
- Kannada (ka, kan)
- Gujarati (gu, guj)
- Malayalam (mal)
- Odia (or, od, oriya)
- Sinhala (si, sinh, sin)
- Gurumukhi (gur)
- Assamese (as)
- Purna-Devanagari

### Classical and Historical Scripts
- Brahmi
- Granth
- Modi
- Sharada
- Siddham

### Special Output Formats

Lipi Lekhika's own schemes, see [Normal](/reference/script_guide#normal) and [Romanized](/reference/script_guide#romanized) in the Script Guide.

- Normal (en, eng, la, lat, nor, norm) - Latin/ASCII output
- Romanized (rom) - Romanized transliteration

### Standard Schemes
- IAST (iast) - with diacritics (`kṛṣṇa`), capital letters are read too (`Kṛṣṇa`). Unlike Romanized, `e` / `o` are the long ए / ओ, `ḷ` is the vocalic ऌ and ळ is `ḻ`
- ITRANS (itrans) - ASCII, ITRANS 5.3 with its alternate spellings (`kRRiShNa`, also `kR^iShNa`)
- Harvard-Kyoto (hk) - ASCII, case sensitive (`kRSNa`)
- SLP1 (slp1, slp) - ASCII, one letter for each sound (`kfzRa`)

## Supported Languages

Languages that use scripts different from their name or have specific abbreviations:

- English (en, eng) → Normal script
- Sanskrit (sa, san) → Devanagari script
- Hindi (hi, hin) → Devanagari script
- Marathi (mar) → Devanagari script
- Nepali (ne, nep) → Devanagari script
- Punjabi (pun) → Gurumukhi script
