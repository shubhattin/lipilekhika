# lipilekhika-macros

Internal procedural macros for the [`lipilekhika`](https://crates.io/crates/lipilekhika) crate.

They expand the plain script/language lists in `src/scripts.rs` and the custom option keys in
`src/custom_options.rs` (both generated by `lipilekhika-datagen`) into the public `Script`,
`ScriptListEnum` and `CustomOptions` types.

This crate is an implementation detail of `lipilekhika` and has no stable API of its own.
