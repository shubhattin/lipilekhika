# macOS: install steps and hurdles for a new user

What a new user goes through to install Lipi Lekhika on macOS from the website, recorded on 2026-11-14 with the released **pc-app@v1.1.2** on a clean Mac mini (M2 Pro, macOS 27.2): no earlier copy, no settings, no permission entry. Everything was done in the GUI as a user would: Safari, Finder, Spotlight, System Settings.

Background: [#234](https://github.com/shubhattin/lipilekhika/issues/234) (event tap vs input method), [#236](https://github.com/shubhattin/lipilekhika/pull/236) (the macOS app), [#235](https://github.com/shubhattin/lipilekhika/pull/235) (signing with the project's self-signed certificate). First written as issue [#238](https://github.com/shubhattin/lipilekhika/issues/238).

## Steps

| #   | Step                                                                                           | What the user sees                                                                                                                                                                   | Hurdle?                                                                                                        |
| --- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 1   | Open [lipilekhika.in/download](https://lipilekhika.in/download/), click **Download for macOS** | The page detects macOS: "Disk image (.dmg, drag to Applications) · version 1.1.2 · 25 MB"                                                                                            | –                                                                                                              |
| 2   | Safari's first download from the site                                                          | "Do you want to allow downloads on lipilekhika.in?" → **Allow**                                                                                                                      | Small (normal Safari behaviour, once per site)                                                                 |
| 3   | Open the dmg from Safari's Downloads list                                                      | A Finder window with **Lipi Lekhika** and an **Applications** shortcut. No prompt: the dmg is not signed, and a dmg signed with a self-signed certificate was refused ("Not Opened") | **Yes:** no arrow or "drag here" text, so a Mac beginner may not know to drag the app onto Applications        |
| 4   | Drag Lipi Lekhika onto Applications                                                            | The app is copied                                                                                                                                                                    | –                                                                                                              |
| 5   | Open it (Spotlight finds it, with its icon)                                                    | **"Lipi Lekhika" Not Opened**: "Apple could not verify… free of malware…", buttons **Done** and **Move to Bin**                                                                      | **Yes, the biggest one:** nothing mentions Open Anyway, so without the download page note most users stop here |
| 6   | System Settings → Privacy & Security                                                           | **Open Anyway** is at the very bottom of a long page ("Lipi Lekhika was blocked to protect your Mac.")                                                                               | **Yes:** hard to find, you scroll past every privacy category                                                  |
| 7   | Click **Open Anyway**                                                                          | "Open Lipi Lekhika? … Don't open this unless you are certain…", buttons **Move to Bin** (highlighted default), **Open Anyway**, **Done**                                             | **Yes:** pressing Return moves the app to the Bin                                                              |
| 8   | Confirm                                                                                        | Admin name and password ("You are attempting to open an app that may cause harm…")                                                                                                   | **Yes:** a standard (non-admin) user cannot continue alone                                                     |
| 9   | The app starts                                                                                 | Main window: "Typing: Needs permission", the notice and **Open System Settings**. macOS's own Accessibility prompt opens too                                                         | –                                                                                                              |
| 10  | Click **Open System Settings** in the app                                                      | It opens _Privacy & Security → Device Control and Data Access_ (macOS 27; _Accessibility_ before), with Lipi Lekhika already listed, switched off                                    | –                                                                                                              |
| 11  | Turn the switch on                                                                             | Admin password again ("Privacy & Security is trying to modify your system settings")                                                                                                 | Small (a second password prompt)                                                                               |
| 12  | Back in the app                                                                                | The notice goes away and typing works at once (⌥X / ⌥C), no restart                                                                                                                  | –                                                                                                              |

After that, typing in TextEdit (⌥X on/off, ⌥C, namaste → नमस्ते, kRShNa → कृष्ण, bhAratam → भारतम्, saMskRtam → संस्कृतम्, shrI → श्री, ki → कि) matched the typing engine. Updates keep the permission: tested on CI builds #77 → #79 → #80, all signed with the same certificate.

## What would remove which hurdle

| Hurdle                                                                        | Fix                                                                                                                                                                              | Cost     |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Steps 5–8 (Gatekeeper: Not Opened, Open Anyway, confirmation, admin password) | Apple Developer ID + notarization: at most a one-click "downloaded from the internet, open?"                                                                                     | $99/year |
| Steps 9–11 (Accessibility, 2nd password)                                      | None: Apple asks the user for this for every app, notarized or not. Our in-app notice and button already make it short                                                           | –        |
| Step 3 (no "drag here" hint)                                                  | A dmg background image with an arrow and "Drag to Applications" (window layout and icon positions in the image)                                                                  | Small    |
| Step 5 (dialog does not mention Open Anyway)                                  | One more line on the download page: the first dialog only offers Done or Move to Bin → click **Done**, then System Settings → Privacy & Security → scroll down → **Open Anyway** | Small    |
| Step 7 (Move to Bin is the default)                                           | Same note: click **Open Anyway**, not the highlighted button                                                                                                                     | Small    |
| Step 8 (needs an admin)                                                       | Notarization only                                                                                                                                                                | $99/year |
