Lipi Parivartaka for Linux (part of Lipi Lekhika, https://lipilekhika.in)

Run it from here:   ./lipiparivartaka
Add it to the app menu (for your user):   ./install.sh
Remove it again:   ./install.sh --uninstall

It draws with Vulkan, or OpenGL ES (Mesa, or your GPU's driver), like most desktops have.
To type in any app on Linux, use the Lipi Lekhika Fcitx5 plugin:
https://github.com/shubhattin/lipilekhika/blob/main/plugins/fcitx5/README.md
